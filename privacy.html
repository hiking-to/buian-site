Privacy policy

Effective 30 October 2026

This policy explains how Buian LLC ("we") handles information on this website and in our internal tool Inside You Stats. Our Etsy shops and the Keepsake Restoration website have their own policies on those sites.

This website

This website has no accounts, forms, cookies, analytics or advertising. Our hosting provider (GitHub Pages) may keep standard server logs, such as IP addresses, for security. If you email us, we use your message only to reply.

Inside You Stats and YouTube API Services

YouTube API Services. Inside You Stats uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses it. The tool is not offered to the public. It has a single user: the owner of the YouTube channel Inside You (@insideyoubodyscience), which belongs to Buian LLC.

What it accesses. With the owner's permission, the tool uses these Google scopes: youtube.readonly (channel and video statistics), yt-analytics.readonly (YouTube Analytics reports for the owner's own channel) and youtube.upload (uploading the owner's own videos to the owner's own channel).

How the data is used. Statistics are used only to build a daily summary for the channel owner. Uploads send only video files and texts the owner prepared, including title, description, tags, publish time and the "altered or synthetic content" disclosure. The tool never edits or deletes videos it did not upload, and never reads or changes any other channel.

Storage. The access token and a daily snapshot of the channel's own numbers are kept on the owner's private computer. API data is refreshed daily, and statistics snapshots older than 30 days are deleted. Nothing is stored on third-party servers.

Sharing. Data is not sold, shared or transferred to anyone, and is not used for advertising or to train AI models.

Google API Services User Data Policy. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion. Access can be removed at any time in Google security settings (third-party access). After revocation the stored token stops working, and it is deleted together with all stored statistics within 7 days. Deletion can also be requested by email.

Your rights

You can ask us what information we hold about you, and ask us to correct or delete it. California residents have these rights under the CCPA. We do not sell or share personal information.
